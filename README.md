# Hawssa Trainer (React)

Vite + React 19 + TypeScript panel for Hawssa trainers.

## Scripts

- `pnpm dev` — start dev server
- `pnpm build` — typecheck and production build
- `pnpm preview` — preview production build locally
- `pnpm lint` — run ESLint

## Environment

Set `VITE_API_BASE_URL` if the API is not the default host configured in the app.
